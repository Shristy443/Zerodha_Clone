# Zerodha Clone

A responsive **Zerodha-inspired trading platform frontend** built using **React.js**. This project recreates the design and user interface of various Zerodha pages with responsive layouts, navigation, and reusable React components.

## 🚀 Live Demo

**Live Website:*
zerodha-clone-project-bod3y1onx-shristy1.vercel.app*


## 📌 Features

* Responsive landing page
* Navigation bar with multiple routes
* Home page
* About page
* Products page
* Pricing page
* Signup page
* Support page
* FAQ section
* Reusable React components
* Responsive design for mobile and desktop
* Client-side routing

## 🛠️ Tech Stack

* **React.js**
* **JavaScript**
* **HTML5**
* **CSS3**
* **React Router**
* **Bootstrap**

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Shristy443/Zerodha_Clone.git
```

Navigate to the frontend directory:

```bash
cd Zerodha_Clone/frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will run locally at:

```text
http://localhost:3000
```

## 📦 Build

To create a production build:

```bash
npm run build
```
